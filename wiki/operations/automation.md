# Agent and librarian readiness

[Brain home](../index.md)

No reader, contributor or recurring agent is verified in this template. Follow [scheduling](../../docs/SCHEDULING.md) and [acceptance](../../docs/ACCEPTANCE.md).

For each reader record agent/host/connector, actual clone/reference, bootstrap path, inspected brain commit, successful fresh-session read and contribution receipt. For the librarian record assigned identity, authority, actual scheduler job ID, host/time zone, cadence, workspace, command/reference, next run, real manual result, first scheduled result, overlap policy, notification behavior and disable instructions. Keep credentials out.

Use explicit states: not-configured, read-ready, contribute-ready, scheduled-awaiting-first-run, verified, failed or blocked. A mock adapter, dry run, local config or saved prompt does not establish an operational recurring agent.
