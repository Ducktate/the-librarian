# Agent and librarian readiness

[Brain home](../index.md)

No reader, contributor or recurring agent is verified in this template. Follow [scheduling](../../docs/SCHEDULING.md) and [acceptance](../../docs/ACCEPTANCE.md).

For each reader record agent/host/connector, actual clone/reference, bootstrap path, inspected brain commit, successful fresh-session bounded read and v2 contribution receipt. For the librarian record assigned identity, authority, operator/session/run UUID, actual scheduler job ID, host, chosen time zone/time/cadence, workspace, command/reference, verified next timestamp/offset, DST behavior, real manual result, first scheduled result, deduplication/concurrency, notification destination/preferences and disable instructions. Keep credentials out.

Daily executive summaries are opt-in. Otherwise notify meaningful changes, failures and required decisions only. Executive and detailed audit reports are separate views with explicit date/time zone/as-of and coverage limits. Runtime role routing must use actual backend-supported controls and preserve the main/voice model; record resolved metadata when available, never assumed model switches or fabricated costs.

Use explicit states: not-configured, read-ready, contribute-ready, scheduled-awaiting-first-run, verified, failed or blocked. A mock adapter, dry run, local config or saved prompt does not establish an operational recurring agent.
