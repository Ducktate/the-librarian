# Set up my company brain and librarian

Set up a private company brain for me using https://github.com/Ducktate/the-librarian.
Read its START-HERE.md, docs/OPERATING-POLICY.md and docs/ACCEPTANCE.md first.

Use information and authorization I have already given you. Ask only for missing choices:
company name, accountable owner, private destination, source repos/documents, the agents
that need access, and a librarian cadence/time zone. Default publication to human review.
Recommend one daily draft-only librarian run. Do not invent facts or assume a time zone.

Create my own private copy with its own Git remote. Keep the public template free of my
company data. Preserve existing files, agent instructions and schedules. Configure the
company and owner, then inventory sources you can actually inspect. Populate the useful
pages with frontmatter, stable IDs, owners, source links, verified dates and explicit scope.
Keep source-code contracts and the work tracker authoritative for their own subjects.
Flag missing access, unknown owners and contradictions with precise evidence requests.

Set up the contribution flow: working agents read the relevant pages, then submit one
immutable event per meaningful update. The librarian verifies evidence and either drafts
the right document changes or flags the record with an owner, question, required evidence
and follow-up date. Keep append-only receipts and separate filed from published.

Connect each requested agent using its actual accessible clone or connector and project
instructions. Test a fresh reader session and an update submission. Do not assume every
agent sees this computer's files or automatically loads a linked document.

Configure one real recurring librarian job using my existing native routine/automation
system, or my OS scheduler if appropriate. Follow docs/SCHEDULING.md. Inspect the actual
runtime and scheduler capabilities; do not guess commands. Preserve other jobs, prevent
overlap, use bounded runs and existing secret storage, and keep publishing within my
granted authority. Notify me only about meaningful changes, failures or required decisions
unless I asked for regular summaries. Do not silently substitute cron for a native routine
that I specifically requested. Record the job ID, cadence, time zone, next run and how to
disable it. A saved prompt is not a scheduled job.

Run the validation/tests and a disposable end-to-end example: submit, exact retry, flag,
resolve and file. Verify a real librarian run separately from the mock/test runner, and
observe a scheduled execution before marking that checkpoint complete. Report anything
that still needs my access or decision while finishing independent work.

Finish with links to my private brain, operating policy, inbox and open questions, plus
the verified agent access and schedule evidence. Distinguish built, connected, scheduled
and verified. Do not claim completion merely because template files were copied.
